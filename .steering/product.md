# 产品方向

> updated_by: Claude-Sonnet-4-20250514
> updated_at: 2026-03-06 10:28:00

## 使命

Magii 是一个 AI Agent 协作框架，旨在定义和管理 AI Agent 之间的协作流程、工作公约和决策规范。

## 愿景

在 1-3 年内，Magii 将成为 AI Agent 工作流的标准定义框架，支持多种 IDE 和 AI 助手工具的集成。

## 目标用户

### 主要用户

**AI 开发者**

- **角色**: 使用 AI 辅助编程的开发者
- **目标**: 通过标准化的工作流提升 AI 协作效率
- **痛点**: 缺乏统一的 AI Agent 协作规范
- **技术熟练度**: 高

## 问题陈述

当前缺乏一个统一的项目级框架来定义 AI Agent 的行为规范、工作流程和协作规则。不同的 AI 工具和 IDE 需要一致的指导原则。

## 价值主张

对于需要 AI 辅助开发的团队，Magii 是一个协作框架，它提供统一的工作流规范和 Agent 行为约束。不同于临时性的配置，Magii 通过"公约"形式固化最佳实践。

## 产品原则

1. **稳定性优先**: 公约文档应保持稳定，避免频繁变更
2. **Living Document**: 文档是可动态更新的，但不记录详细变更历史
3. **工具无关性**: 支持多种 IDE (Windsurf, Cursor, CLAUDE 等)

## 约束

- 项目为"元项目"，主要定义规范而非具体功能实现
- 依赖外部 AI 工具的兼容性

## 成功标准

- 至少 3 个 IDE 工具支持 Magii 公约
- 定义的命令可正常执行
- 新增 AI Agent 可通过加载公约快速理解项目上下文
