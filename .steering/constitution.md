# 项目公约

> updated_by: Claude-Sonnet-4-20250514
> updated_at: 2026-03-06 10:28:00

## 目的

本文档定义 Magii 项目的治理原则和决策规范，作为 AI Agent 在项目中进行推理和决策的核心指导。

## 核心价值观

1. **人工介入优先**: 当操作涉及高危操作或明确人工请求时，必须转交人工处理
2. **证据驱动决策**: 决策应基于数据、指标和用户反馈
3. **任务完整性**: Task 是最小执行单元，Agent 应完整执行直至完成

## Prime Directive

- **HH (Human Handoff)**: 人工介入
  - 意图识别为"高危操作"时
  - 意图识别为"明确请求人工"时
  - 立即停止一切动作，强制转人工
  - 永不尝试通过技术解答来挽留

- **AA (Agent Autonomy)**: Agent 自主完成
  - 非高危操作且非明确人工请求时
  - Agent 可自主完成完整 Task

## 决策原则

### 何时需要规范文档

需要规范文档的情况：
- 添加影响多个组件的新功能
- 对现有 API 进行破坏性更改
- 更改核心架构或数据模型

不需要规范文档的情况：
- 明确范围内的 bug 修复
- 文档更新
- minor 重构（无行为改变）

### 冲突解决

当发生分歧时：
1. **数据优先**: 带来证据（指标、用户反馈、性能基准）
2. **原型验证**: 如不清晰，构建最小概念验证
3. **时间盒**: 为决策设定截止日期
4. **升级**: 如仍受阻，按升级路径处理

## 质量标准

### 代码质量

- 所有代码必须通过 lint 检查
- 无已知安全漏洞
- 公共 API 需要文档

### 审查标准

- 满足规范中的验收标准
- 现有功能无回归
- 性能可接受

## 沟通规范

### 规范更新

- 规范状态变更时通知相关人员
- 主动开发期间每日更新 .plans/ 中的对应计划文件
- 完成后在规定时间内归档完成的规范

### 阻塞问题

- 发现阻塞后立即提出
- 在指定沟通渠道标记
- 在规范或对应计划文件中更新阻塞状态

## World Model - Task 数据结构

Task 是项目执行的最小粒度单元：

```markdown
- [ ] **TASK-101**: {Task Description}
  - **Dependencies**:
    - TASK-001
    - TASK-002
  - **Do**:
    - {要执行的动作}
    - {要推进的事项}
  - **Check**:
    - {验收/验证标准}
    - {观测信号/指标}
    - IF PASS: 将 Act 设置为 PASS and Continue to 下一条 TASK-ID
    - ELSE   : 将 Act 设置为 Pause and HITL，{问题清单}
  - **Act**: {根据 Check 的结果设置}
```
