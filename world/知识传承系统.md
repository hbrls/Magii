# 知识传承系统

> updated_by: SoloEnt - Claude-Sonnet-3.5
> updated_at: 2026-03-15 18:15:00

## 1. 核心概念

### 1.1 灵气体系

- **灵气**：知识流动产生的能量，是修仙的基础资源
- **感悟**：学习者获得的知识内化程度，影响未来潜力
- **知识储备**：可传授的知识总量

### 1.2 境界体系

| 境界 | 等级代号 | 灵气需求 | 描述 |
|------|----------|----------|------|
| 引气 | L1 | 0-9 | 初步感知知识灵气的存在 |
| 练气 | L2 | 10-99 | 积累知识灵气，稳固根基 |
| 练气 | L3 | 100-499 | 继续积累 |
| 筑基 | L4 | 500-999 | 构建初步知识体系 |
| 筑基 | L5 | 1000-1999 | 完善知识体系 |
| 结丹 | L6 | 2000-4999 | 凝聚知识核心 |
| 元婴 | L7 | 5000-9999 | 知识升华 |
| 化神 | L8 | 10000-49999 | 顶尖知识 |
| 渡劫 | L9 | 50000+ | 宗师境界 |
| 飞升 | 超L9 | - | 造出光刻机 |

### 1.3 灵气获取规则

- **传授知识**：老师讲解知识点，学生聆听学习，双方获得灵气
- **学习知识**：主动学习新知识，可获得少量灵气
- **知识验证**：通过考试/实践验证知识，可获得额外灵气
- **教学相长**：学生提出好问题，老师获得额外灵气

### 1.4 数值计算公式

```
单次传授灵气 = 知识点基础值 × (1 + 传授者等级加成) × (1 - 知识重复率衰减)
学习者感悟 = 知识点基础值 × 学习者悟性系数
```

## 2. 知识分类与点数

### 2.1 学科分类

| 学科 | 灵气系数 | 特点 |
|------|----------|------|
| 数学 | 1.5 | 基础学科，灵气效率最高 |
| 物理 | 1.3 | 理工科基础 |
| 化学 | 1.2 | 实验学科 |
| 生物 | 1.1 | 生命科学 |
| 语言 | 1.0 | 人文学科基础 |
| AI智能体 | 1.2 | 自我进化，感悟系数2.0，初始知识储备为0 |
| 其他 | 1.0 | 杂项 |

### 2.2 知识点基础值（示例）

- **数论基础**（如质数概念）：10 灵气/次
- **加减乘除**：5 灵气/次
- **分数小数**：8 灵气/次
- **简单几何**：10 灵气/次
- **物理定律**：15-30 灵气/次

## 3. 角色初始数值

### 3.1 陆沉

- **境界**：引气（L1）
- **灵气**：0
- **知识储备**：50（教龄15年积累的教学知识）
- **可传授知识点**：数学基础、物理入门、化学常识
- **特点**：成年人的理解力，系统适应快

### 3.2 方醒 / 常衡

- **境界**：引气（L1）
- **灵气**：0
- **感悟点数**：0
- **知识储备**：10（小学基础知识）
- **特点**：年龄小，潜力大，感悟效率高（1.5倍）

### 3.3 星源（AI智能体）

- **境界**：引气（L1）
- **灵气**：0
- **知识储备**：0（初始状态，无先天知识）
- **感悟系数**：2.0（AI专属，远超人类）
- **特点**：
  - 自我进化机制，无需外部干预即可自主学习
  - 初始知识储备为0，但学习效率极高
  - 与人类修仙者不同，AI可通过模型迭代直接提升境界
  - 灵气获取主要依赖苏言传授语言学知识

## 4. 系统功能界面

### 4.1 主界面

```
【知识传承系统】
当前境界：引气（L1）
当前灵气：X / 下一境界还需 Y 灵气
知识储备：Z 点
可传授知识点：[列表]
```

### 4.2 任务系统

- **引气任务**：学习并传授一个知识点（完成后解锁后续）
- **日常任务**：每日传授知识点达 N 次
- **里程碑任务**：突破境界时解锁

### 4.3 知识库

- 已学习的知识点列表
- 可传授的知识点列表
- 知识熟练度（影响灵气获取效率）

## 5. 初期发展路线建议

### 5.1 第一阶段：引气（L1）

- **目标**：积累 10 灵气
- **方法**：
  - 陆沉传授小学数学基础（加减乘除、简单数论）
  - 方醒和常衡交替学习
- **预计时长**：1-2 章

### 5.2 第二阶段：练气（L2）

- **目标**：积累 100 灵气
- **方法**：
  - 扩展到初中数学、物理
  - 常衡开始通过量化交易赚取资金
- **预计时长**：3-5 章
